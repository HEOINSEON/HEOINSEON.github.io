도덕 수업 도구함 🍯

도덕 수업과 학급 운영을 위해 교사가 직접 만든 웹 도구 29개를 모아 둔 곳입니다. 회원가입이나 앱 설치 없이 인터넷 브라우저에서 바로 사용할 수 있습니다.

이용 안내 개인정보 처리방침 문의

도구함 입장

수업 시간에 안내받은 입장 비밀번호를 입력하세요.

이용 안내, 문의, 개인정보 처리방침은 비밀번호 없이 볼 수 있습니다.

이용 안내

사용 환경

  • 크롬, 웨일, 엣지, 사파리 등 최신 웹 브라우저
  • 학교 크롬북·태블릿·PC·스마트폰 모두 지원(반응형 화면)
  • 회원가입·로그인·앱 설치 필요 없음
  • 깃허브 페이지(github.io)로 운영하며, 수업 전에 학교 와이파이에서 접속되는지 확인 후 사용

수업에서 사용하는 방법

  1. 교사가 수업 시간에 해당 도구의 주소나 QR코드를 안내합니다.
  2. 학생은 안내받은 도구에 접속해 활동합니다.
  3. 응답을 저장하는 도구는 학번·이름 등 꼭 필요한 정보만 입력합니다.
  4. 주민등록번호, 전화번호, 주소 등은 어떤 도구에도 입력하지 않습니다.

콘텐츠와 안전

  • 도덕과 교육과정과 학급 활동 목표에 맞추어 교사가 직접 설계하고 수업에서 검증했습니다.
  • 광고, 결제, 외부 쇼핑 링크가 없습니다.
  • AI 도구는 수업 주제와 관련된 질문 생성에만 쓰입니다. 결과는 교사가 수업 중에 함께 검토합니다.
